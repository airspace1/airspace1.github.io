Family Agent privacy policy

Last updated October 24, 2026

Family Agent is a private tool used by one family. Only the two parents who run it sign in to it with their Google accounts.

What it accesses

  • Email in its own Gmail inbox, which receives only messages the parents choose to forward.
  • A family calendar the parents share with it, to add and check events.
  • The parents' Gmail filter settings, only to add forwarding filters they approve. It cannot read the parents' email.

How data is used and stored

  • Data is used only to keep the family's calendar and reminders up to date.
  • Summaries are stored on one computer in the family's home. Full email bodies are not stored.
  • Content is processed by Anthropic's Claude API to read and summarize it. It is not used for advertising.
  • Data is never sold or shared with anyone else.

Google user data

Family Agent's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Either parent can remove Family Agent's access at any time at myaccount.google.com/permissions.
